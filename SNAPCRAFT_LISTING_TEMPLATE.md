### 2. Description (Markdown Supported)

```markdown
Clocki is a tiny, frameless, always-on-top desktop focus timer and HUD clock overlay designed for tracking daily focus hours without cluttering your workspace.

### Key Features
- **Minimal HUD Overlay**: Ultra-compact desktop widget that stays visible above all windows.
- **Proportional Corner Resizing**: Click and drag any corner to scale up or down proportionally.
- **Dual Display Modes**:
  - **Focus Timer Mode**: Tracks total daily focus hours (`0.00h`).
  - **Real-Time Clock Mode**: Displays your system local time (`HH:MM:SS`) when expanded.
- **Cyberpunk Color Themes**:
  - Deus Ex (Gold / Amber)
  - Cyber Cyan (Neon Cyan)
  - Dark Red (Alert Red)
  - Neon Purple (Deep Violet)
  - Monochrome (Black & White)
- **Instant Mouse & Keyboard Controls**:
  - **Left Click**: Pause / Resume.
  - **Double Click**: Reset focus timer to `0.00h`.
  - **Right Click**: Open theme selector, mode switcher, hide, or quit menu.
  - **Ctrl+Alt+C**: Global hotkey to Pause / Resume.
  - **Ctrl+Alt+H**: Global hotkey to Show / Hide.
  - **Ctrl+Alt+R**: Global hotkey to Reset.
- **Automatic Persistence**: Daily focus time, active theme, and window positions survive system restarts.
```
